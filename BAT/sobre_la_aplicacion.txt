La aplicación se compone de 11 ficheros .py, todos simples módulos conteniendo 
funciones, excepto calibrado.py que contiene dos clases. El módulo principal es MEGA.py
Los módulos que contienen las ecuaciones del modelo son:

ahorro.py
calibrado.
demanda.py
exterior.py
gobierno.py
producción.py

el módulo argumentos.y contiene los más de 50 parámetros con los que se seleccionan 
las distintas posibilidades de la aplicación. La única función de este módulo define como 
debe interpretarse la línea de comandos, parámetro a parámetro. Cada parámetro 
contiene una serie de atributos donde los esenciales son el nombre, el tipo, el valor por 
defecto y un comentario de ayuda.

El valor por defecto es muy importante porque es el valor que tendrá el parámetro si no 
hay línea de comandos, que es lo normal si la aplicación se ejecuta dentro de un entorno 
de desarrollo, en este caso hay que venir a este módulo y cambiar los valores por defecto 
de los parámetros que sea necesario.

Esto no es una forma recomendable de ejecutar casos de forma sistemática ya que es 
casi seguro que se olvidará cambiar algún valor por defecto, por eso es importante la línea 
de comando ya que se puede tener una para cada caso con sus parámetros correctos y 
mejor aún, podemos tener un fichero batch (WINDOWS) para ejecutar cada caso, por 
ejemplo, para el caso en el que se incrementa la demanda del producto AP3 en 1000 
unidades y se aplica un arancel a este producto del 0.003825 por uno, el fichero batch es

Al final de cada línea (excepto la última) aparece el carácter ^ que indica que la línea 
continua, porque la línea de comandos es una sola línea.

Con el comando cd C:\MEGA\MEGA nos situamos en la carpeta donde se encuentra 
el módulo MEGA.py

Así mismo es importante indicar la senda donde encontrar el interprete python.exe 
que corresponda, mucho mejor que dejar que WINDOWS los busque es sus 
parámetros de entorno. 

C:\Users\Usuario\AppData\Local\Programs\Python\Python312\python.exe

Una gran cantidad de las ‘líneas’ de la aplicación se encargan de mostrar en pantalla y 
en el fichero de salida, los datos (obtenidos de la MCS), generar gráficos e informes.

Unas pocas ‘líneas’ preparan las variables que necesita el procedimiento 
‘scipy.differential_evolution’, en especial el intervalo de existencis (bnds) de las 
variables que forman el vector solución.

Finalmente, no pocas ‘líneas’ se encargan de elaborar los informes a partir del 
resultado de ‘scipy.differential_evolution’.

El módulo funciones.py contiene funciones auxiliares para la impresión de informes.

El módulo restricciones.py es el que contendría las definiciones de las restricciones 
(funciones) en el caso de que nuestro modelo las contuviera. En el libro no se incluye 
ningún caso con restricciones y este módulo contiene un ejemplo de dos 
restricciones muy simples, la función de la restricción se limita a devolver el valor de 
las exportaciones, o importaciones del producto AP3, para limitarlo al intervalo 
definido en la restricción.

La función más importante del del módulo principal MEGA.py es:

def sec_ecuaciones(vec_opt, MUESTRA_PROGRESO) que junto a:

def calcula_desvios(res_ecuaciones, MUESTRA_PROGRESO)

constituyen la función objetivo que se quiere minimizar y calculan el mérito de una 
posible solución ‘vec_opt’. Devuelven un valor escalar positivo que cuanto menor es, 
mayor es el mérito de ‘vec_opt’, si es cero, significa que ‘vec_opt’ es la solución.

La secuencia de actividad del módulo MEGA.py es la siguiente:

•	Obtención de los parámetros de la aplicación
•	Lectura de la MCS
•	Creación de las clases (datos y parámetros) que actuarán como contenedores 
de los datos de la MCS y los parámetros calculados para el modelo.
•	Particularización de datos y parámetros según el escenario (NCASO)
•	Preparación de una solución inicial para ‘scipy.differential_evolution’ y los 
intervalos de existencia de las variables incluidas en la solución (bnds)
•	Ejecución de ‘scipy.differential_evolution’
•	Mostrar resultados.
